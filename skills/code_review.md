# 代码审查流程

1. 先用 `read_file` / `grep_text` 读全相关代码，不要只读片段。
2. 按下列维度检查，每条给出 **文件:行号** 与 **修改建议**：
   - 正确性：边界条件、异常路径、类型不匹配、资源未释放
   - 兼容性：是否用了 Python 3.9+ 语法（目标 3.8）、Windows 路径与编码问题
   - 安全：命令注入、路径穿越、 secrets 硬编码
   - 性能：循环内的重复 I/O、不必要的全量读取
3. 输出格式：

| 严重度 | 位置 | 问题 | 建议 |
|---|---|---|---|
| 高 | file.py:12 | ... | ... |

4. 最后给出「最小改动方案」：不超过 5 条，能直接照做。
